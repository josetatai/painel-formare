# Lembretes do painel

- [ ] Etiquetas UTM nos anúncios: NÃO mexer nos anúncios atuais (editar pode reiniciar o aprendizado da campanha). Quando criar um anúncio novo, ou na próxima vez que precisar mudar a campanha, preencher em Rastreamento → Parâmetros de URL: utm_source=meta&utm_medium=anuncio&utm_campaign={{campaign.name}}&utm_content={{ad.name}}
- [ ] Posts orgânicos: usar links com ?utm_source=instagram (ou whatsapp, email…) para separar a origem das vendas.
- [ ] Importar o histórico de vendas da Kiwify (precisa da chave de API: Kiwify → Apps → API → Client ID, Client Secret e Account ID, colados em Ajustes).
- [ ] Marcar como "facebook/instagram" as visitas que chegam com fbclid (clique dentro do Facebook/Instagram) quando não houver etiqueta.
- [ ] Opcional: apagar o webhook antigo "Formare Play" na Kiwify.
- [ ] Opcional: deixar a página do Servidor 4.0 atualizar sozinha pelo GitHub (webhook da Hostinger).
